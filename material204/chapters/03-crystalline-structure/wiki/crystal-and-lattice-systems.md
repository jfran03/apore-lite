# Crystal and Lattice Systems

## Definition

- **Crystal systems:** defined by unit cell geometry (lengths, angles, symmetry) → **7 types**
- **Lattice systems (Bravais lattices):** add lattice point arrangement (primitive, body-centered, face-centered, etc.) → **14 unique Bravais lattices**
> Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slide 7)

## Key Concepts

- **7 crystal systems, 14 crystal lattices:** the distinction is that crystal systems are set by cell geometry alone, while Bravais lattices additionally account for where the lattice points sit within the cell.
  > Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slide 7)

- **The seven crystal systems and their geometry:**

  | System | Edge lengths | Angles | Mineral shown |
  |---|---|---|---|
  | Cubic | a = b = c | α = β = γ = 90° | Fluorite |
  | Tetragonal | a = b ≠ c | α = β = γ = 90° | Wulfenite |
  | Orthorhombic | a ≠ b ≠ c | α = β = γ = 90° | Olivine |
  | Hexagonal | a = b ≠ c | α = β = 90°, γ = 120° | Emerald |
  | Trigonal | a = b = c | α = β = γ ≠ 90° | Rhodochrosite |
  | Monoclinic | a ≠ b ≠ c | α = γ = 90°, β ≠ 90° | Azurite |
  | Triclinic | a ≠ b ≠ c | α ≠ β ≠ γ ≠ 90° | Amazonite |
  > Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slide 7)

- **Cubic crystal system condition:** a = b = c and α = β = γ = 90°.
  > Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slide 21)

## Examples

- **Example (Cubic system):** Simple cubic, Body-centered cubic (BCC), Face-centered cubic (FCC) — three different lattice-point arrangements within one crystal system.
