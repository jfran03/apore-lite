# Unit Cell Geometry and Lattice Constants

## Definition

The lattice constant *a* is related to the atomic radius *r* through the direction along which atoms touch in a given structure.

| Structure | Where atoms touch | Relationship used to find *a* |
|---|---|---|
| Simple cubic | Along the edge | a = 2r |
| BCC | Along the body diagonal | √3 a = 4r |
| FCC | Along the face diagonal | √2 a = 4r |
> Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slide 16)

Solved for *a*:
- a = 2r for SC
- a = 4r/√3 for BCC
- a = 2√2 r for FCC
> Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slides 31, 33, 35)

## Key Concepts

- **Cube diagonals from Pythagoras:** for a cube of edge length *a*,
  - (face diagonal)² = a² + a² = 2a², so **face diagonal = √2 a**
  - (body diagonal)² = (√2 a)² + a² = 2a² + a² = 3a², so **body diagonal = √3 a**
  > Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slide 16)

- **BCC derivation:** the body diagonal spans 4R, so (4R)² = a² + (√2a)² → 16R² = 3a² → a = 4R/√3.
  > Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slide 21)

- **FCC derivation:** the face diagonal spans 4R, so a² + a² = (4R)² → 2a² = 16R² → a = 4R/√2 = 2√2 R.
  > Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slides 21, 32)

- **Practical use:** if *r* is given, you can find *a*.
  > Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slide 32)

- **Cubic unit cell volume:** V_C = a³ for cubic structures.
  > Source: F26-D2L-Chapter 3 - Crystalline Structure-Part 1.pdf (slides 30, 31)
